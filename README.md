# Allcargo

Allcargo is a modern global logistics, freight forwarding, and real-time shipment tracking platform.

## Features
- **Real-Time Tracking:** Instant status, route checkpoints, and live manifest details.
- **Enterprise Operations:** Comprehensive dispatch and manifest management.
- **Intermodal Logistics:** Air, ocean, and ground freight coordination.
- **Customer Support:** Live interactive support widget and automated status alerts.

## Project Structure
- `frontend/`: Static HTML5, Tailwind CSS, and vanilla JavaScript interface.
- `frontend-react/`: Modern React + Vite application with interactive dashboard and tracking maps.
- `backend/`: Express server for API routing and mock database storage.
